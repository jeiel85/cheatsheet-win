## Fn Cheatsheet v0.1.7 — current fan mode

**App**
- Keys that cycle a mode can now show what is on right now. On the ASUS ExpertBook P1 / B1 15" (confirmed on a P1503CVA), the Fn+F line reads **Now: Standard / Whisper / Performance** (Korean: **현재 표준 / 저소음 / 고성능**).
- The mode is read once, when the sheet opens, from a registry value that ASUS System Control Interface keeps up to date. No admin rights, nothing changed, nothing read while the sheet is hidden. If the value is missing or unknown, the line looks as before.
- `FnCheatsheet.exe --device` also prints the current key states it can read.

**Data**
- Profiles can give a key an optional `state` (registry DWORD + value names); see CONTRIBUTING.md.
