## Fn Cheatsheet v0.1.8 — current state on every laptop

**App**
- The cheat sheet now shows what's on right now for the standard keys, on every supported laptop:
  - Mute, mic mute, airplane mode: **On / Off** (켜짐 / 꺼짐)
  - Volume and brightness: **%**
  - Display mode: **PC only / Duplicate / Extend / Second only**, only while a second display is connected
- The badge sits at the bottom of the key cap (a row grows only if one of its keys has a badge), or after the label in the Fn + key list. "On" and named modes are highlighted; values and "Off" are a quiet chip.
- Everything is read once, when the sheet opens, from standard Windows settings (audio endpoint, power plan brightness, display configuration, radio state). No admin rights, nothing changed, nothing read while the sheet is hidden. A state that can't be read shows no badge.
- `FnCheatsheet.exe --device` prints all of these states.

**Data**
- Standard states need nothing in the profile: they follow the key's icon (`mute`, `mic-mute`, `airplane`, `vol-up`/`vol-down`, `bright-up`/`bright-down`, `display`). See CONTRIBUTING.md.
