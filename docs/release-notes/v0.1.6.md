## Fn Cheatsheet v0.1.6 — signed updates

**App**
- Updates are now signed. Each release carries `FnCheatsheet.exe.sig`, a minisign (Ed25519) signature made on the maintainer's PC with a key that never touches GitHub. From this version on, the app installs an update only if that signature is valid for that exact file name and version — so even someone who took over the GitHub account or swapped release files could not push a fake update.
- The SHA-256 file is still checked; it catches broken downloads.
- Versions up to 0.1.5 don't check signatures and update to this one as usual.

**Release process**
- Releases are now built, signed and published by `tools/release.ps1` on the maintainer's PC instead of GitHub Actions.
