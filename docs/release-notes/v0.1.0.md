## Fn Cheatsheet v0.1.0 — first release

왼쪽 **Ctrl**을 길게 누르면 내 노트북 모델의 Fn 키 기능이 화면에 떠요. / Hold **Left Ctrl** to see what your laptop's Fn keys do.

- **130 profiles** (ASUS 36 · Lenovo 94) built from official ASUS E-Manuals and Lenovo User Guides / PSREF, each with source links
  - ASUS ExpertBook, Zenbook, Vivobook, ROG, TUF
  - Lenovo ThinkPad (T / X1 / X13 / E / L / P / Z, 2021–2025), IdeaPad, Yoga, ThinkBook, Legion, LOQ
- **Detects your model** from SMBIOS (ASUS model code, Lenovo machine type / model name) — and **never guesses**: unknown or ambiguous models ask you to pick one in Settings
- **Hold to show**, cancelled by any other key, click, scroll or mouse movement (Ctrl+C / Ctrl+click keep working); not shown over full-screen apps and games
- **Native Rust + Win32**: one ~2 MB exe, no runtime, a few MB of memory in the tray, never elevated
- **Auto-update** from GitHub releases (once a day, SHA-256 verified, rollback on failure)
- Korean / English, dark / light, per-monitor DPI

Download `FnCheatsheet.exe` below and run it. SmartScreen may warn about a new unsigned app: **More info → Run anyway**. `FnCheatsheet.exe.sha256` has the checksum.
