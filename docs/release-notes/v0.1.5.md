## Fn Cheatsheet v0.1.5 — borderless full-screen games

**App**
- "Not over full-screen apps and games" now also covers *borderless windowed* games and browser/video full screen (F11). Until now the app relied only on Windows' own full-screen signal, which reports exclusive full-screen D3D apps and presentation mode but can miss a caption-less window resized over the monitor.
- The foreground window counts as full screen when its visible bounds cover its whole monitor (not just the work area). The desktop, the taskbar, the app's own windows and ordinary maximized windows (which fill the monitor only when the taskbar auto-hides) never count.
- New console command for checking a particular game: `FnCheatsheet.exe --foreground 5` waits 5 seconds (switch to the game meanwhile), then prints what it saw.
