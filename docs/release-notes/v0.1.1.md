## Fn Cheatsheet v0.1.1 — hardening

Fixes from [Hardening candidates: v0.1.0 (#1)](https://github.com/jeiel85/cheatsheet-win/issues/1). v0.1.0 updates itself to this version within a day.

**App**
- The updater now checks that the downloaded exe's version resource matches the release tag before installing it
- A failed update check is retried after about 3 hours instead of the next day
- The keyboard hook is re-installed after unlocking the PC, after resume from sleep, and hourly — Windows can silently drop a low-level hook

**Release & CI**
- Releases are created as drafts and published only after both assets are confirmed, so "latest" can never point at a release without the exe
- GitHub Actions pinned to commit SHAs (and moved off the deprecated Node 20 versions); `persist-credentials: false`; Dependabot for Actions and Cargo

**Website**
- Scripts and styles moved to files; the page now ships a strict Content-Security-Policy

**Look & feel**
- New app icon (Windows 11 Fluent style: Fn keycap + cheat-sheet card; a simplified keycap for tray-sized 16–40 px)
- Opaque sheet so text behind it no longer shows through; the status line is fully localized

**Lighter**
- The overlay is drawn with Direct2D's software rasterizer and the graphics objects are released after each draw — memory after showing the sheet dropped from ~45 MB to ~8–12 MB private
- The hold delay is measured by the hook thread's own wait loop instead of a thread timer
