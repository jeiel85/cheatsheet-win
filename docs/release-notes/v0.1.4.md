## Fn Cheatsheet v0.1.4 — FnProbe fixes

**FnProbe.exe**
- The raw HID / raw keyboard channel never delivered anything: the hidden window that receives `WM_INPUT` was only held by a local variable, so the .NET garbage collector destroyed it a few seconds after start. Reports from v0.1.3 therefore did not check the HID channel — please run FnProbe again.
- In a Remote Desktop session the verdict now says what was actually checked: only the hardware-wide channels (vendor WMI, ACPI). The keyboard/HID channels see the remote keyboard there, not the laptop's own.

The app itself is unchanged.
